# Energy App Review Sentiment Analysis and Rating Prediction

## Project Overview

This project focuses on text analytics using public customer reviews from energy-sector mobile applications. The goal is to build an end-to-end NLP machine learning pipeline that can analyze review text, classify sentiment, and predict app review ratings.

The selected dataset includes reviews from energy supplier apps, EV charging apps, mobility apps, and smart energy service apps.
The project includes:

- Text data loading
- Exploratory data analysis
- Text preprocessing
- Feature extraction using CountVectorizer and TF-IDF
- Sentiment classification
- Rating prediction
- Model training using Naive Bayes and Logistic Regression
- Model evaluation using accuracy, classification report, and confusion matrix
- Visualization of common words and review patterns

## Problem Statement

Customer reviews contain valuable information about customer satisfaction. However, manually reading thousands of reviews is time-consuming.

This project uses NLP and machine learning to automatically classify review sentiment and predict review ratings based on text content.

## Planned Models

The project will compare two classical machine learning models:

1. Multinomial Naive Bayes
2. Logistic Regression

## Planned Feature Extraction Methods

1. CountVectorizer
2. TF-IDF Vectorizer
