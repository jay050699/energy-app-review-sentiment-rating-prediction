# Dataset Notes

## Dataset Selection Status

Dataset not selected yet.

The final dataset will be selected before the data loading and EDA stage.

## Required Dataset Type

This project requires a review-based dataset.

The dataset should contain customer/user review text and either rating labels or sentiment labels.

## Minimum Required Columns

The dataset should contain:

| Column | Description |
|---|---|
| review_text | The written review text |
| rating | Numerical rating, usually from 1 to 5 |

## Optional Useful Columns

| Column | Description |
|---|---|
| date | Review date |
| product_name | Product name |
| business_name | Business or restaurant name |
| category | Product/business category |
| verified_purchase | Whether review is verified |
| helpful_votes | Number of helpful votes |

## Possible Dataset Domains

Possible review dataset types:

1. Restaurant reviews
2. Hotel reviews
3. Product reviews
4. Movie reviews
5. Mobile app reviews
6. Course reviews
7. Company/employee reviews

## Dataset Selection Criteria

The final dataset should be:

- Publicly available
- Suitable for GitHub portfolio use
- Clear enough for sentiment analysis
- Not too large for local processing
- Preferably available in CSV format
- Contains review text and rating
